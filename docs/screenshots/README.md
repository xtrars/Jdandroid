# Bildschirmfotos

Platzhalter. Hier sollen vier Bildschirmfotos der App liegen, die in der
README eingebunden sind:

| Datei | Ansicht |
|---|---|
| `downloads.png` | Download-Liste mit Paket, Fortschritt und Entpack-Status |
| `linksammler.png` | Linksammler mit online geprüften Links |
| `konten.png` | Kontenübersicht mit Restmenge und Balken |
| `einstellungen.png` | Einstellungen (Click'n'Load, Passwortliste, Ausschlussmuster) |

Empfehlung: Hochkant, Material-You-Farben des Geräts, Breite 1080 px, ohne
persönliche Daten (Benutzernamen, Restmengen, Dateinamen anonymisieren).
